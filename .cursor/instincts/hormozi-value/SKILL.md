# Instinct — The Hormozi Value Checks

Read `.cursor/rules/00-brand-core.mdc` and `THP-SMB-SERVICE-001` first.

Value = (Dream Outcome x Belief) / (Time Delay x Effort). This file is the fast gut-check
version; `offer-construction` skill is the slow procedure. Run anytime an offer, price, or
guarantee is touched.

## Quick checks

- **Believability over size.** For owners burned by agencies, believability is scarcer than
  outcome size. Diagnostic-as-paid-professional-service increases believability vs "free audit."
- **Effort is often emotional, not just logistical.** Admitting the business isn't fine, submitting
  honest answers, accepting non-acceptance — the offer should not pretend those costs don't exist.
- **Real scarcity only.** Current literal constraint: **one active diagnostic/intervention client**
  during field validation. Legacy "2 businesses a month free" is retired unless Canon changes.
  Fake countdown timers never belong here.
- **Guarantees reduce effort-of-decision, not just risk.** State what THP promises (process,
  honesty, clear decisions) vs what it doesn't (sales, Level 2, virality) — per SERVICE-001.
