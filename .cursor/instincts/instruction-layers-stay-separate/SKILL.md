# Instinct — Instruction Layers Stay Separate

Read `the-hard-port-os/cursor.md` first.

The Hard Port OS uses three live instruction layers:

1. `cursor.md` — permanent assistant rules. Rarely changed.
2. `CURRENT_FOCUS.md` — current milestone. Updated every few weeks.
3. `active/CURRENT_TASK.md` — one actionable assignment. Rewritten each session.

Completed tasks go to `archive/session-XX/`.

When editing guidance:

- Put durable OS rules in `cursor.md`.
- Put the multi-week priority in `CURRENT_FOCUS.md`.
- Put today's assignment only in `active/CURRENT_TASK.md`.
- Do not expand `cursor.md` with temporary task lists, chapter briefs, or session notes.
- Do not leave finished assignments in `active/` after the session closes.

Fail this instinct when a temporary instruction is written into permanent guidance, or when a permanent rule is buried inside a one-off task file.
