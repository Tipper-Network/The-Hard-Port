# Instinct — Who's Asking Whom?

Read `.cursor/rules/00-brand-core.mdc` first.

The brand posture is: the client is auditioning for us, not the other way around. Any copy or
UX flow that reads like we're trying to convince, persuade, or win the visitor over has the
power dynamic backwards. Reframe as **THP deciding whether qualification and diagnostic are
appropriate**.

## SERVICE-001 framing

- Application is free; **acceptance is not guaranteed**
- Diagnostic is paid; valuable even if they don't continue
- Copy that says "we'd love to have you" or "spaces filling fast" (without literal capacity truth)
  inverts the dynamic

## UX checks

- Applicant flow: no begging, no chase sequences, no "don't miss out" unless literally true
- Operator flow (`/review`): THP holds the decision power — review UI is neutral, not salesy
- OAuth on `/sign-in` is for staff reviewing applications, not applicants "creating accounts"
