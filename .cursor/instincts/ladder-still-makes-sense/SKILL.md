# Instinct — Does the Ladder Still Make Sense?

Read `.cursor/rules/02-conversion-funnel.mdc` first.

Any time a new section, page, or flow is added, re-walk the funnel top to bottom as if seeing
it cold from a social link. If the escalation breaks — if it gets softer instead of harder, if
a section could be moved to a different rung without changing anything — that's the instinct
to flag it before it ships, even if no single rule was technically violated.

## When instincts and rules conflict

They shouldn't, if the rules were written well. If an instinct flags something a rule
explicitly allows, treat that as a signal the rule file needs updating — not as permission to
ignore the instinct. Flag it back to the human rather than silently overriding either one.
