# Instinct — Does the Ladder Still Make Sense?

Read `.cursor/rules/02-conversion-funnel.mdc` first.

Any time a new section, page, or flow is added, re-walk the funnel top to bottom as if arriving
from a YouTube link. The ladder is **SERVICE-001 aligned** (condition → mechanism → boundaries →
capacity), not the legacy agency stack (boosting, packages, free slots).

If escalation breaks — softer instead of harder, agency language mid-page, a pricing grid where
boundaries should be — flag it before ship, even if no single rule was technically violated.

## Red flags

- Free-slot or Port/Sea/Ocean language reappears on the homepage
- A section sells "content" or "rebrand" as the primary offer
- Operator sign-in surfaced in the applicant scroll path (footer excepted)
- CTA labels flat across the page ("Apply" repeated from hero to footer)

## When instincts and rules conflict

They shouldn't, if the rules were written well. If an instinct flags something a rule explicitly
allows, treat that as a signal the rule file needs updating. Flag it to the human rather than
silently overriding either one.
