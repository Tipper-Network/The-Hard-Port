# Instinct — Could This Exist on Any Other Agency's Website?

Read `.cursor/rules/00-brand-core.mdc` first.

Before shipping any new section, ask: could this sentence, this component, this layout be
copy-pasted onto a generic marketing agency site with just the logo swapped? If yes, it's not
finished. This is the fastest gut-check for corporate drift, faster than scanning against the
banned-words list in `.cursor/rules/01-copywriting-standards.mdc`.
