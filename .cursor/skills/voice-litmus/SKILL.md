# Skill — Voice Litmus Test

Read `.cursor/rules/01-copywriting-standards.mdc` first.

1. Read the paragraph out loud.
2. Ask: does this sound like it's explaining the brand, or being the brand? If explaining,
   rewrite in the direct/declarative mode (see the before/after example in copywriting standards).
3. Cut every sentence that could be removed without losing an idea — brevity is enforcement,
   not style preference.
4. Check the result against `small-business-psychology` — would this specific reader recognize
   themselves in it, or does it read as copy written about them rather than to them?
