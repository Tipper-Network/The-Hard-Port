# Skill — Launching a New Page / Funnel Entry Point

Read `.cursor/rules/00-brand-core.mdc` and `.cursor/rules/02-conversion-funnel.mdc` first.

1. Start from the 9-rung structure — don't invent a new structure per campaign.
2. Run the `positioning-audience` skill first if the new page targets a different angle or segment.
3. Reuse the canonical letter, or a tonally-matched variant, for the agitation rung — extend the
   existing emotional core rather than writing a new one from scratch each time.
4. Confirm mobile-first layout and load-speed budget per `.cursor/rules/04-ux-friction.mdc`
   before adding any heavy media.
5. Run the `section-audit` skill on every section before launch.
