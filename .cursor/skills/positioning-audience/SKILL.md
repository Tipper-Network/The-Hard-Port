# Skill — Positioning / Smallest Viable Audience (Godin procedure)

Read `.cursor/rules/00-brand-core.mdc`, `godin-remarkable`, and `THP-SMB-SERVICE-001` first.

Use this before writing identity-defining copy (hero lines, condition sections, new campaign
angles) — not for routine section edits.

## Procedure

1. **Write the widest possible version of the audience first** ("small business owners"), then
   narrow it at least twice more. For THP SMB service, the working anchor is **Level 1**:
   established microbusiness with paying customers, surviving on founder effort, not pre-launch.
2. **Write the explicit exclusion.** Pre-launch, hobby-stage, "just need more posts," people
   wanting reassurance without examination — state exclusions plainly.
3. **Find the identity line, not the feature line.** Who the reader is (stuck-but-operating),
   not what THP sells (diagnostic, intervention). Test: would they want to be this person?
4. **Check against letter, hero, and `/work-with-us`** — same person throughout, not a bolt-on
   segment.
5. Run `aggression-calibration` — narrow aggressively; don't insult outsiders for sport.
