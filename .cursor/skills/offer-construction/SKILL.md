# Skill — Offer Construction (Hormozi Grand Slam Offer procedure)

Read `.cursor/rules/00-brand-core.mdc` first. Use the `hormozi-value` instinct for small edits to existing offers.

Use this when building a new tier, free-slot mechanic, or bundled package — not for small copy
edits to an existing offer.

## Procedure

1. **Name the dream outcome in the reader's own words**, not agency language. Not "increased
   brand visibility" — "people recognize your business without you explaining it every time."
2. **List every believable proof point** that supports the reader thinking Hard Port can
   deliver it — real numbers only, per `hormozi-value`. If the list is thin, that's information:
   lean on the honesty-as-proof instinct rather than inventing more.
3. **List every friction point** in time and effort the reader currently associates with
   "getting a marketing agency" — long contracts, vague deliverables, waiting months for
   results, having to manage the agency themselves.
4. **Strip or reverse each friction point** in the actual offer structure: shorter commitment,
   named deliverables, a visible first step, a stated timeline.
5. **Stack, don't just discount.** Instead of dropping the price, add a component only Hard
   Port would think to include — the free-slot mechanic, the "we call you" positioning — that
   a generic competitor's offer wouldn't have.
6. **Write the tier name and one-line description last**, only after the above is settled, so
   the name reflects a real structural difference (see: Port / Sea / Ocean already doing this
   correctly by tying tier to bravery, not just budget).
7. Run the result through `.cursor/rules/01-copywriting-standards.mdc` and `aggression-calibration`
   before shipping.
