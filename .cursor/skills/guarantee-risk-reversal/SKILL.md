# Skill — Guarantee / Risk Reversal Design

Read `.cursor/rules/00-brand-core.mdc` first.

A guarantee's job is to move risk from the buyer to the seller so the decision gets easier, not
to be a marketing bullet point. Follow this procedure any time one is added or changed.

## Procedure

1. Identify the single biggest reason this specific reader (see `small-business-psychology`)
   hesitates to commit — usually: "I've paid for this before and gotten nothing."
2. Design the guarantee to directly cancel that fear, not a generic fear. A blanket
   "money-back guarantee" is weaker here than something structural, like the free-slot proof
   mechanic already on the site (do the work first, on spec, before any money changes hands).
3. State the guarantee in one plain sentence, no legal hedging language, no asterisks doing the
   real work in fine print — the tone should still sound like the rest of the site, not like a
   terms-of-service page.
4. Make sure the guarantee is something Hard Port can actually deliver on every time — never
   design a guarantee copy could oversell past what operations can back up. This is a
   credibility mechanic; a broken guarantee is worse than no guarantee.
5. Place it near the point of decision (pricing section, apply form), not buried in an FAQ
   where it does no persuasive work.
