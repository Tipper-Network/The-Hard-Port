# Client Workspace Template

> Duplicate this folder for each entity: `clients/THP-CLIENT-XXX/`  
> **Do not store fictional client data in this template.**

## ID convention

`THP-CLIENT-001`, `THP-CLIENT-002`, … assigned at first application receipt.

## Separation rule

| Folders | Role |
|---|---|
| `00-application` – `08-proof` | Client engagement and **client source data** |
| `09-institutional-learning` | **THP internal only** — methodology learnings, not client deliverables |

See [`operations/first-client-readiness/THP-EVIDENCE-STORAGE-RULE.md`](../operations/first-client-readiness/THP-EVIDENCE-STORAGE-RULE.md).

## Stage folders

| Folder | Lifecycle stage | Institutional templates |
|---|---|---|
| `00-application/` | Stage 2 — Application | Application export, routing note |
| `01-qualification/` | Stage 4 — Qualification | [`THP-SMB-TEMPLATE-001`](../knowledge/smb-maturity/instruments/templates/THP-SMB-TEMPLATE-001-qualification-record.md) |
| `02-diagnostic/` | Stages 5–6 — Diagnostic prep & diagnostic | Evidence request, diagnostic findings |
| `03-findings/` | Stage 7 — Findings presentation | Founder response, corrected record |
| `04-commercial/` | Stages 8–9 — Engagement decision & agreement | SOW, signed agreement, consent forms |
| `05-intervention/` | Stages 10–11 — Kickoff & execution | [`THP-SMB-TEMPLATE-002`](../knowledge/smb-intervention/templates/THP-SMB-TEMPLATE-002-intervention-decision-record.md) |
| `06-evidence/` | Ongoing | Client source files (redacted copies as needed) |
| `07-reassessment/` | Stage 13 — Level 2 reassessment | Reassessment record |
| `08-proof/` | Stage 14 / proof | [`THP-SMB-TEMPLATE-006`](../knowledge/smb-proof/templates/THP-SMB-TEMPLATE-006-proof-record.md) |
| `09-institutional-learning/` | Internal | [`THP-FIRST-CLIENT-FIELD-VALIDATION`](../operations/first-client-readiness/templates/THP-FIRST-CLIENT-FIELD-VALIDATION.md), [`THP-SMB-TEMPLATE-003`](../knowledge/smb-intervention/templates/THP-SMB-TEMPLATE-003-institutional-learning-record.md) |
