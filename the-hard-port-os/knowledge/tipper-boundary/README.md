## Feature-Development Gate

Seven conditions; **three real entities** = minimum trigger for **product investigation** — not market validation, not automatic build.

## Field-Validation Boundary

Manual systems must be exercised with real entities before any Tipper feature is scoped.

## Deferred Decisions

- Tipper product roadmap
- Automated data ingestion from client engagements
- Community-facing Tipper features without field evidence

## Conditions That Do Not Justify Product Development

- Single-client request
- Founder preference for software over manual process
- Vanity metrics or follower counts
- Branding/content workflow alone without relationship or decision evidence
- Assumption that Tipper adoption equals Level 2 community gate
