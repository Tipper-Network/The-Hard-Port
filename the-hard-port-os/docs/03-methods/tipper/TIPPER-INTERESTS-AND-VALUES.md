# Tipper Interests and Values

> **Status:** `candidate`, `non_canonical`

## Identity Boundary

Tipper may support voluntary identity and lifestyle exploration, but it must not claim authority over a user's identity or secretly infer personal values and intentions without informed permission.

## Scope

Voluntary interest selection and self-identified values — not covert value extraction.

Institutional definitions of values, beliefs, and principles: [`THP-VALUES-PRINCIPLES-WILL.md`](../../00-foundations/THP-VALUES-PRINCIPLES-WILL.md) (`THP-PH-003`). Do not treat inferred behavior as proof of a user's true value; do not equate measurement with valuation.

## Permitted

- User-selected interests and value statements
- Explicit prompts where the user chooses to identify values
- Visible tags the user can add, edit, or remove
- Community membership the user opts into

## Prohibited

| Requirement | Status |
|---|---|
| Hidden-value inference without consent | **Prohibited** |
| Inferring core values from behavior alone without disclosure | **Prohibited** |
| Treating inferred values as fixed identity traits | **Prohibited** |
| Irreversible inferred identity labels | **Prohibited** |

Values recorded in Tipper reflect what the user **states or confirms**, not what the system secretly deduces.

## Informed Permission

Before using participation data to suggest value-related inferences, Tipper must obtain informed permission and show the inference as provisional and correctable.
