# Tipper Method Documentation

Candidate operational boundaries for Tipper identity, participation, and recommendation systems.

Philosophical source: [`THP-SELF-INTENTION-EXPRESSION.md`](../../00-foundations/THP-SELF-INTENTION-EXPRESSION.md) §19–§20.

## Identity Boundary (all Tipper method documents)

Tipper may support voluntary identity and lifestyle exploration, but it must not claim authority over a user's identity or secretly infer personal values and intentions without informed permission.

## Prohibited (repository-wide)

The following are **not permitted** in Tipper method or product requirements:

- hidden-value inference without consent
- declaration of a user's true identity
- undisclosed psychological profiling
- irreversible inferred identity labels
