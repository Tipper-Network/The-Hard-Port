# Entity Position and Direction Assessment

> **Status:** `candidate`, `non_canonical`  
> **First paid engagement** for the THP-SMB-001 onboarder path.

## Purpose

Establish where the founder and entity currently stand, where they are attempting to go, and what prevents coherent movement between those positions.

**Boundary:** Diagnostic and directional — not unlimited implementation, not a transformation guarantee, not THP operating the business on the client's behalf.

## Assessment Structure

The assessment produces five deliverable components. Question sets, scoring, and interview scripts are **not yet designed** — this document defines structure only.

### 1. Current-Position Assessment

| Field area | Source types |
|---|---|
| Founder's role in the entity | Founder interview, observation |
| Entity operating condition | Observation, records, platform activity |
| Maturity level (Level 1 or 2 only) | [`THP-SMB-LEVELS-001`](../../../knowledge/smb-maturity/THP-SMB-LEVELS-001-maturity-model.md) |
| Current offering | Founder testimony, offering artifacts |
| Customer or community relationship | Observation, founder testimony, customer signals |
| Decision patterns | Interview, action history |
| Existing routines | Observation, calendar/content/ops review |
| Present constraints | Interview, financial/operational context |

### 2. Intention and Alignment Assessment

Compare dimensions from existing methods — do not auto-map to goal/vision/mission/brand:

| Dimension set | Method reference |
|---|---|
| `stated_intention`, `governing_intention`, `enacted_intention`, `perceived_intention` | [`ENTITY-INTENTION-DIMENSIONS.md`](./ENTITY-INTENTION-DIMENSIONS.md) |
| `declared_values`, `governing_priorities`, `operating_principles`, `observed_actions`, `value_principle_contradictions`, `stakeholder_perceptions` | [`ENTITY-VALUES-PRINCIPLES-LOOP.md`](./ENTITY-VALUES-PRINCIPLES-LOOP.md) |

Record contradictions; do not conclude permanent "true" intention or value from repeated action alone.

### 3. Entity Narrative

Business-language operating narrative covering:

- what the entity is;
- who it serves;
- why its work matters;
- current position;
- pursued direction.

This is an **operating narrative** — not necessarily a full branding engagement.

### 4. Distance Map

Document the gap between:

- present position;
- desired Level 2 condition;
- capabilities already present;
- missing capabilities;
- contradictions;
- immediate constraints.

Use **Level 2 only** as the validated target stage. Do not map distance to unvalidated Levels 3–7.

### 5. Initial Operating Plan

Limited action system:

- first priorities;
- defined actions;
- relevant measurements;
- responsibilities;
- feedback checkpoints;
- review point.

Scope is bounded to the first movement — not full transformation.

## Evidence Separation

Each assessment record must distinguish:

- founder testimony;
- THP observation;
- operational data;
- interpretation;
- hypothesis;
- recommended intervention;
- expected consequence.

## Engagement Gates

**Upstream (before this assessment):**

1. [`THP-ENGAGEMENT-READINESS-APPLICATION.md`](./THP-ENGAGEMENT-READINESS-APPLICATION.md) — self-reported intake; routing signals only
2. [`THP-SMB-INSTRUMENT-002`](../../knowledge/smb-maturity/instruments/THP-SMB-INSTRUMENT-002-first-onboarder-diagnostic.md) — **authoritative** qualification gate; must pass before full diagnostic and this assessment
3. Level 1 diagnostic (A–H) — maturity classification within [`THP-SMB-INSTRUMENT-002`](../../knowledge/smb-maturity/instruments/THP-SMB-INSTRUMENT-002-first-onboarder-diagnostic.md)

**Before this assessment proceeds** (consulting / intervention progression — not initial acceptance):

- informed consent and defined scope ([`ENTITY-ENGAGEMENT-BOUNDARIES.md`](./ENTITY-ENGAGEMENT-BOUNDARIES.md));
- qualification outcome **`qualified`** or equivalent verified acceptance — not application completion alone;
- sufficient operating activity for meaningful assessment (verified at qualification, not self-reported only);
- consulting stage gates from [`layer-07-consulting-methodology.md`](../../../intelligence/layer-07-consulting-methodology.md) — **intervention progression gates** (Discovery, Observation, Diagnosis, etc.), **not** initial engagement-acceptance gates.

**Ambiguity note:** Entity Position assessment was previously documented as requiring "readiness confirmed via application." That requirement is **superseded for SMB first-onboarder path** by the application → qualification → diagnostic sequence. Application readiness is a **preliminary signal**; qualification is authoritative.

## What This Assessment Is Not

- Social-media performance audit as primary deliverable
- Predetermined solution before investigation
- Level 3–7 maturity assignment
- Tipper onboarding
- Unlimited implementation scope
