# Active

## What Belongs Here

The current session assignment only.

- [`CURRENT_TASK.md`](./CURRENT_TASK.md) — one actionable assignment for Cursor, rewritten each work session.
- [`forms/`](./forms/) — founder input forms awaiting synthesis (`canonicality: working`, not Canon).

## What Does Not Belong Here

Permanent assistant rules, multi-week milestones, completed tasks, research records, Canon chapters, or session history.

## How Documents Enter

Rewrite `CURRENT_TASK.md` at the start of a session from the current milestone in [`../CURRENT_FOCUS.md`](../CURRENT_FOCUS.md).

## How Documents Leave

When the session ends, archive the completed task under [`../archive/session-XX/`](../archive/) and rewrite or clear `CURRENT_TASK.md`.

## Related Files

- [`../cursor.md`](../cursor.md) — permanent assistant instructions
- [`../CURRENT_FOCUS.md`](../CURRENT_FOCUS.md) — current milestone
- [`../archive/`](../archive/) — completed tasks and session notes
