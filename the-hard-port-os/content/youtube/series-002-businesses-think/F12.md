# F12 — Businesses Think Growth Means Doing More

**Narrative stage:** Recognition

## Believed problem

Need to scale activity to scale the business.

## Core contrast

**More activity** · versus · **a stronger business system**

## Core observation

More products, posts, platforms, promotions, and services can increase complexity without increasing stability.

## Underlying condition

Overwhelm answered with more overwhelm; growth attempted before stability.

## Level 1 dimensions

L1 → L2 transition · all dimensions implicated

## Recognition CTA

List everything you added in the last year to "grow." Which increased complexity without increasing predictability?
