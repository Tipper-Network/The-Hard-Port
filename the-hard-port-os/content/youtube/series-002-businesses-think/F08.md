# F08 — Businesses Think They Need More Customers

**Narrative stage:** Misdiagnosis

## Believed problem

Pipeline empty; need new buyers.

## Core contrast

**More customers** · versus · **fewer forgotten customers**

## Core observation

Many already have customers, previous customers, visitors, inquiries, and supporters—but no system for retaining the relationship.

## Underlying condition

Acquisition prioritized; reactivation and memory absent.

## Level 1 dimensions

C (Retention) · B (Customer understanding)

## Recognition CTA

List everyone who bought in the last year you have not contacted since. That is your hidden list.
