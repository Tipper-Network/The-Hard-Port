# Volume V — Business Ontology

## Purpose

Synthesize accepted entities, relationships, activities, resources, and exchanges required to describe small businesses as systems.

This volume is currently a seed architecture. No chapter is canonical merely because the file exists.

## What Belongs Here

Reviewed synthesis within this volume's purpose, supported by cited research, decisions, systems, and relevant working frameworks.

## What Does Not Belong Here

Client records, unaccepted ontology proposals, diagnostic conclusions, and software-specific data models.
